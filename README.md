Projeto inspirado em plataformas de streaming, desenvolvido para exibir e organizar filmes favoritos de forma personalizada.

## Objetivo
Criar uma interface moderna e interativa para apresentar filmes e conteúdos favoritos, enquanto desenvolve habilidades em front-end e design de interfaces.

## Tecnologias Utilizadas
- HTML
- CSS
- 
## Funcionalidades
- Exibição personalizada de filmes favoritos
- Interface inspirada em streaming platforms
- Layout visual moderno
- Organização de conteúdos por preferência pessoal
- Design responsivo

## Aprendizados
Durante este projeto foram desenvolvidas habilidades em:
- Front-end development
- Estrutura de interfaces
- Design responsivo
- Personalização visual
- Experiência do usuário

## Status
Projeto desenvolvido para prática de programação, design web e criação de interfaces inspiradas em plataformas reais.
